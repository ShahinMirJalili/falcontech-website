**FalconTech Solutions** ist meine eigene Web- & KI-Agentur aus Holzminden. Ich habe das
Unternehmen gegründet, ein 4-köpfiges Team aufgebaut und die komplette technische Plattform
selbst entwickelt — von der Firmen-Website über interne Portale bis zur Akquise-Automatisierung.

## 🏗️ Was ich gebaut habe

- **Firmen-Website** — moderne, Apple-inspirierte Business-Site (clean, mobile-first, DSGVO-konform)
- **Team-Portal** — interne Plattform für Aufgaben, Businessplan und Dashboard
- **Client-Portal** — Kundenbereich mit Login (Supabase Auth)
- **CRM-System** — Verwaltung von **350+ Leads** mit automatisierter Akquise-Pipeline
- **4+ Kunden-Websites** — ausgeliefert und live (u.a. Gastronomie, Dienstleister)

## 🛠️ Tech-Stack

| Bereich | Technologie |
|---------|-------------|
| Frontend | HTML5, CSS3, JavaScript |
| Backend / DB | Supabase, Node.js |
| Hosting | Netlify, Vercel |
| Domain / Mail | IONOS |
| Automatisierung | Claude API, eigene CLI-Tools |
